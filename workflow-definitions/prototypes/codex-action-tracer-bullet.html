首个 codex-action Tracer Bullet 应证明什么？

这个可丢弃 Prototype（原型）让我们亲手比较两条最小真实 Workflow：只读 PR Review 与写入型 ticket-to-PR。问题不是哪条最终价值更大，而是哪条能用最少机制验证 Workflow-first → Compatible Executor → Agent Action → Agent Runtime 的边界，同时产生可信、可观察的证据。
