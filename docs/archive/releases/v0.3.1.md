# Graph Engineering v0.3.1

Graph Engineering `v0.3.1` 与 `@tutar/graph-engineering@0.3.1` 共同交付项目自有的 Workflow 集合和安装 CLI。

## Highlights

- CLI 改为一次安装并检查整套 Workflow；`init/check development` 旧任务选择接口不再接受。
- PR Review Task 退出当前源码、测试、打包与安装支持；已有 Consumer 文件保持项目所有，不会被自动删除或接管。
- `migrate` 可预览并迁移来源可确认且未修改的旧 Development 安装；遇到未知来源、本地修改、目标冲突、新旧安装并存或旧 PR Review 时停止。
- Coding Task 使用项目自有的 Codex Goal Action，通过 App Server 执行原生 Work Goal，并在 `blocked` 或 `budgetLimited` 后最多执行一次固定预算的 Handoff Goal。
- Runtime Token Budget 采用累计上限，Handoff 获得 `100,000` token，Coding Task 总上限为 `500,000` token。
- Coding Task 支持经过脱敏的近实时日志，并避免重复渲染已完成的 Agent 消息。

## Install

在目标 Git 仓库根目录执行：

```bash
npx --yes @tutar/graph-engineering@0.3.1 init --dry-run
npx --yes @tutar/graph-engineering@0.3.1 init
npx --yes @tutar/graph-engineering@0.3.1 check
```

CLI 不注册 runner、不登录 Codex、不安装 Skill、不提交文件，也不修改 GitHub Settings。`check` 的文件匹配不证明 runner、认证或真实任务执行已经验收。

## Migration

先预览可识别的旧 Development 安装：

```bash
npx --yes @tutar/graph-engineering@0.3.1 migrate
```

交互确认后才会修改；非交互环境必须显式传入 `--apply`。旧 PR Review 安装需要人工决定如何处理。
