# Graph Engineering v0.3.3

Graph Engineering `v0.3.3` 与 `@tutar/graph-engineering@0.3.3` 提供独立 Workflow 版本升级入口，保留项目自有修改，并修复 Coding Action 流式日志的行分帧与安全模式增量去重。基于 [PR #106](https://github.com/tutar/graph-engineering/pull/106)。历史包与 Release 不回写。

## Upgrade

已安装 0.3.1 的项目可以使用新版 CLI 升级到指定的已发布 0.3.2：

```bash
npx --yes @tutar/graph-engineering@0.3.3 upgrade --to 0.3.2
npx --yes @tutar/graph-engineering@0.3.3 upgrade --to 0.3.2 --apply
npx --yes @tutar/graph-engineering@0.3.2 check
```

CLI 版本与目标项目安装版本独立；省略 `--to` 时目标为 0.3.3。默认只读显示路径计划、包来源与 diff，显式 `--apply` 才写入。`--project` 选择项目；`--from-package` 与 `--to-package` 支持可信原始 npm 包的离线升级。新版 CLI 的 `init` 仍只负责首次安装，`migrate` 仍只负责旧 Loop Engineering 来源迁移。

三方合并保留 runner、触发条件、Prompt 等可合并修改。冲突或无法核对旧安装来源时整套停止，不写冲突标记；应用前复核现场，可捕获写入失败恢复原文件与记录，整套文件成功后才写目标模板来源。不保证断电/强制终止恢复或多文件事务原子性。完整接口与离线步骤见 [CLI 文档](../../../packages/cli/README.md#workflow-版本升级033-起)。

## Install

```bash
npx --yes @tutar/graph-engineering@0.3.3 init --dry-run
npx --yes @tutar/graph-engineering@0.3.3 init
npx --yes @tutar/graph-engineering@0.3.3 check
```

## Verification boundary

CLI 与 Workflow 完整回归串行运行 120/120 通过。打包的 0.3.3 CLI 使用真实已发布 0.3.1/0.3.2 包完成在线与离线预览、应用，核对新增 Development 本地 Action、Coding Skill 桥接文件、保留的项目修改及目标来源记录。另验证默认升级到打包 CLI 的 0.3.3 目标。同版本、来源拒绝、冲突整套阻断、四阶段失败恢复和连续升级均有回归覆盖。逐项验收、命令与包校验值保存在 [Issue #105](https://github.com/tutar/graph-engineering/issues/105)。

文件升级与静态 `check` 不证明 runner 认证、隔离或真实 Workflow 任务执行。
