## Included

- 与 `v0.1.0`–`v0.1.2` 并存、可整体复制并由 Consumer Project 自有的完整 `github-pr-review/v0.1.3` 文件集合。
- Manual dispatch 使用只读 GitHub token 读取当前 PR facts，并与自动事件一致排除 Draft、closed 或不可读取的目标。
- 只传 Action 支持的 legacy `safety-strategy: read-only`，不再与 `permission-profile` 组合。
- review job 冻结到 `[self-hosted, Linux, X64, codex]`，route 与 trusted publish jobs 继续独立运行。
- 维护版 `tutar/codex-action` 锁定到 commit `f33581290086e62dc34d420a7f1862477fc2b503`，上游基线锁定为 `openai/codex-action@86365089eb2b84e0a8fb0717b304f8bdcb13b20e`，并显式固定 `codex-version: 0.153.4`。
- Runner-backed Codex Authentication：不传 repository `OPENAI_API_KEY`，由 Action 使用 runner 默认 Codex home 中的既有登录状态；Workflow 不直接调用 runner CLI。
- 保留 write-access gate、same-repository PR、Read-only Effect Mode、结构化 Standards/Spec 双轴结果、可信 Check publisher、SHA freshness、幂等与 fail-closed 边界。

## Evidence boundary

Candidate Publication Gate 提供 local static and automated contract evidence（本地静态与自动化契约证据），包括维护版 Action 的认证回归、人工 Draft 路由的 fake GitHub API 测试与精确 Action 输入断言；它仍不证明真实 runner、登录状态、网络或 Consumer Project 兼容。公开 Consumer Project 必须以该冻结组合完整执行相关 Cases，并产生独立 Evidence Bundle；不得拼接失败的 `v0.1.1` 或 `v0.1.2` 结果。
